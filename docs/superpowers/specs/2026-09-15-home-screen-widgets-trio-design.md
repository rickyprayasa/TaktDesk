# Design Specification: ZYKL Android Home Screen Widgets Trio (4x1 Strip, 2x2 Analog Dial, 4x2 Task Dispenser)

## 1. Overview & Objectives
Extend the ZYKL application's presence on Android with a comprehensive suite of three distinct, hardware-inspired home screen widgets embodying Dieter Rams' Ten Principles of Good Design:
1. **Widget 1: "Monastic Focus Strip" (4x1)** — Horizontal single-row quick-action status and focus launcher.
2. **Widget 2: "AW10 Pure Analog Dial Face" (2x2)** — Horological Braun AW10 stopwatch face with procedurally rendered amber hand indicating focus position.
3. **Widget 3: "Rotary Task Dispenser Strip" (4x2)** — Thermal paper receipt roll presenting active tasks with monospace checkboxes and direct app launching.

All widgets adhere to:
- **Zero background battery drain:** Driven purely by event-based Flutter-to-native RemoteViews updates over `com.takt.desk/app_widget` MethodChannel.
- **Offline & Private:** All data persists locally in `takt_widget_prefs` SharedPreferences.
- **Dieter Rams / Braun Aesthetics:** Basalt slate / Obsidian chassis (`#14171A`), warm bone / parchment (`#F5F3EB`), filament amber accents (`#FF9E00`), and monospace typography.
- **Namespace Cleanliness:** 100% compliance with `com.zykl.app` / `com.takt.desk`, zero occurrences of `tuneeca`.

## 2. Architecture & Data Flow

```
┌─────────────────────────────────────────────────────────────┐
│                       FLUTTER LAYER                         │
│  - chronoDialControllerProvider (status, seconds, target)   │
│  - todayFocusStatsProvider (cycles, minutes focused)        │
│  - appDatabase.watchActiveTasks() (up to 5 active tasks)    │
└──────────────────────────────┬──────────────────────────────┘
                               │ MethodChannel:
                               │ com.takt.desk/app_widget
                               │ 'updateAllWidgetData'
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                    ANDROID NATIVE LAYER                     │
│  MainActivity.kt                                            │
│   ├── Stores payload into SharedPreferences                 │
│   │   (`takt_widget_prefs`)                                 │
│   └── Triggers broadcast / updates:                         │
│       ├── TaktAppWidgetProvider (existing 2x2 Telemetry)    │
│       ├── TaktFocusStripWidgetProvider (4x1 Strip)          │
│       ├── TaktAnalogDialWidgetProvider (2x2 Analog Dial)    │
│       └── TaktTaskDispenserWidgetProvider (4x2 Dispenser)   │
└─────────────────────────────────────────────────────────────┘
```

### Shared Preferences Keys (`takt_widget_prefs`)
- `cycles_completed` (int)
- `cycles_target` (int)
- `minutes_focused` (int)
- `status` (String: "STANDBY", "FOCUS", "BREAK")
- `remaining_seconds` (int)
- `target_minutes` (int)
- `tasks_json` (String: JSON array of `[{id, title, is_completed}]`)

## 3. Widget Specifications

### 3.1 Widget 1: "Monastic Focus Strip" (4x1 Horizontal)
- **Dimensions:** Target cells: 4 wide x 1 high (`minWidth: 250dp`, `minHeight: 48dp`).
- **Layout File:** `res/layout/takt_appwidget_focus_strip_4x1.xml`
- **Metadata File:** `res/xml/takt_appwidget_focus_strip_info.xml`
- **Class:** `TaktFocusStripWidgetProvider.kt`
- **Visual Elements:**
  - **Left Block:** `ZYKL // MOD. 01` badge and current status label (`STANDBY` or `RUNNING 24:15`).
  - **Center Block:** 4 Micro-LED indicators (`ic_widget_led_amber` / `ic_widget_led_dim`) displaying completed quadrant cycles today.
  - **Right Action Button:** Tactile button container with filament amber border (`[ START ➔ ]` when in standby, `[ FOCUSING ]` or `[ BREAK ]` when active).
  - **Interaction:** Tap anywhere (or action button) fires a `PendingIntent` that opens `MainActivity` into the active timer console.

### 3.2 Widget 2: "AW10 Pure Analog Dial Face" (2x2 Circular)
- **Dimensions:** Target cells: 2 wide x 2 high (`minWidth: 110dp`, `minHeight: 110dp`).
- **Layout File:** `res/layout/takt_appwidget_analog_dial_2x2.xml`
- **Metadata File:** `res/xml/takt_appwidget_analog_dial_info.xml`
- **Class:** `TaktAnalogDialWidgetProvider.kt`
- **Visual Elements:**
  - Iconic Braun AW10 aesthetic rendered via a composite circular view:
    - Outer dark matte bezel ring (`#1C1E22`).
    - Inner warm bone face (`#EDEAE2`).
    - Center `ZYKL` typography and 12/24/60 hash ticks.
    - Procedurally rendered Bitmap generated by native Kotlin Canvas drawing the signature amber needle (`#FF9E00`) with circular center boss, pointing accurately to the remaining/current minute angle (`angle = (remainingSeconds / totalSeconds) * 360f`).
  - **Interaction:** Tap launches `MainActivity` directly into the full ChronoDial interactive view.

### 3.3 Widget 3: "Rotary Task Dispenser Strip" (4x2 Receipt Paper)
- **Dimensions:** Target cells: 4 wide x 2 high (`minWidth: 250dp`, `minHeight: 110dp`).
- **Layout File:** `res/layout/takt_appwidget_task_dispenser_4x2.xml`
- **Metadata File:** `res/xml/takt_appwidget_task_dispenser_info.xml`
- **Class:** `TaktTaskDispenserWidgetProvider.kt`
- **Visual Elements:**
  - Off-white thermal receipt paper background (`#F5F3EB`) with subtle drop shadow and serrated sawtooth bottom edge.
  - Header: `ACTIVE TASKS // DISPENSER` · Date (`15 SEP 2026`) · Quota (`X / 5 TASKS`).
  - 5 item rows: Monospace checkbox `[ ]` (or `[✓]`), title text (strikethrough when finished).
  - Footer Action: `[ + OPEN DISPENSER ↗ ]`.
  - **Interaction:** Tap launches `MainActivity` directly opening the Rotary Task Dispenser drawer.
